# Documentação técnica

Esta pasta concentra documentação que explica **por que** e **como** o sistema foi construído.

- `architecture/` — arquitetura, diagramas e fluxos;
- `adr/` — Architecture Decision Records;
- `api/` — contratos REST;
- `events/` — eventos AMQP e contratos de mensagens;
- `diagrams/` — fontes dos diagramas.

A documentação deve acompanhar o código: decisões importantes não devem existir apenas na apresentação final.
