# Frontend

Aplicação **Home Broker** em React + TypeScript.

Responsabilidades previstas:

- autenticação e sessão;
- visão de mercado;
- envio e acompanhamento de ordens;
- livro de ofertas;
- carteira e patrimônio;
- histórico de negociações;
- atualização em tempo real via WebSocket/STOMP.

O código da aplicação será criado nesta pasta.
